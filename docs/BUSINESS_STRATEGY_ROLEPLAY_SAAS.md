# 事業戦略メモ: ロールプレイ練習プロダクトの収益化

> 作成: 2026-07-20 / 対象: workplace-roleplay を起点とした対人スキル練習プロダクトの事業化
> 位置づけ: 検討メモ（意思決定の叩き台）。数字は市場相場からの概算であり、要検証。

## 0. 出発点の問い

1. ハラスメントロールプレイだけ切り出して売り出したい。広告？サブスク？
2. だったら「○○系ロープレ構築SaaS」にしたらどうか？

この2つの問いに答える形で戦略を整理する。

## 1. 手元にある資産（確認済み）

`scenarios/data/` に45本のシナリオ。うちハラスメント系として切り出せる資産が10本以上ある。

- `harassment_gray_zones.yaml` — 「指導と叱責の境界線」「世代間コミュニケーションのズレ」等、**グレーゾーン判断**を扱う（差別化の核）
- `harassment_training.yaml` — 「パワハラ防止の基本」等、防止研修フォーマット
- `scenario37`（上司の執拗な叱責・パワハラ）、`scenario42`（ロジハラ上司に論破され続ける）、`scenario40〜43` の【上司役】視点シナリオ 等

エンジン層（YAMLスキーマ ＋ AIペルソナ ＋ SSEチャット ＋ フィードバック生成）は**ハラスメント固有ではなく対人スキル練習全般に汎用**。ハラスメント固有なのはコンテンツ層（YAML）だけ。

YAMLスキーマの主要フィールド: `ai_role` / `user_role` / `initial_situation` / `learning_points` / `feedback_points`。

## 2. 問い①への結論: 広告でもB2C月額でもなく「B2B（企業研修）」

「広告か、サブスクか」という二択自体を組み替えるべき。

### 広告が不正解な理由
- **経済性が成立しない**: 広告はトラフィック商売。RPMは高くても数百円/1000PV。ニッチな研修ツールが必要PVに届かない。届いても月数万円規模。
- **商品を殺す**: ハラスメント対応の練習会話の横に広告 → 人事は絶対に導入しない。センシティブな会話データ×広告トラッキングはプライバシー面で致命傷。広告は「B2Bへの道を閉ざして小銭を得る」選択。

### B2C個人サブスクが主軸にならない理由
- 個人が「ハラスメント対処の練習」に月額を払う動機は弱い。悩む人は転職・相談窓口に流れる。支払い意思額は月数百円が上限。
- 恥の感情が絡む領域は個人課金と相性が悪い。
- **ただし無料の個人向け入口はリード獲得装置として価値がある**（→ §4）。

### B2Bが刺さる理由: 「練習ツール」ではなく「法対応の証跡」を売る
- **改正労働施策総合推進法（パワハラ防止法）**により、2022年4月から中小企業含む全企業にハラスメント防止の**措置義務**。→ これは「あったら良い教育」ではなく**コンプライアンス支出**。
- 企業は既に外部講師研修（1回数十万円）、eラーニング（1人1,000〜3,000円）に支払っている。

既存手段の弱点とAIロールプレイの差別化:

| 既存手段 | 弱点 | AIロールプレイの差別化 |
|---|---|---|
| 動画eラーニング | 受け身。「視聴した」だけで判断力がつかない | 能動的に発話して失敗できる |
| 集合ロールプレイ研修 | 高額・心理的負担大・年1回きり | 安価・一人で何度でも・心理的安全 |
| どちらも | グレーゾーン判断を測れない | `harassment_gray_zones` がまさにここを突く |

人事が本当に欲しいのはチャット画面ではなく、**「誰がいつ受講し、どんな理解度だったか」の記録＝措置義務を果たした証跡**。売り物の中心は管理画面とレポート。

## 3. 商品・価格設計（問い①）

- **モデル**: 年額 per-seat ライセンス（＝B2Bサブスク）。目安 **1人 年3,000〜6,000円**、または「50名パック 年20〜30万円」。eラーニング相場より少し上でも「実践型」で正当化できる。
- **入口商品**: いきなり年契約は売れない。**単発「管理職向けAIロールプレイ研修パッケージ」1社10〜30万円**から。社労士・研修会社の既存メニューにOEM/紹介手数料で乗せるのが最短販路（法改正のたびに売るネタを探している層）。
- **無料B2C版**: グレーゾーン診断だけ無料公開 →「あなたの会社でも」導線でB2Bリードに転換。広告の代わりの集客装置。

## 4. 問い②への結論: 「エンジンは汎用に設計、商品は縦に売る」

「構築SaaS」は**目的地としては正しいが、入口にすると死ぬ**。

### 「構築SaaS」を最初の商品にするのが罠な理由
1. **買い手が作らない（空白キャンバス問題）**: 人事はシナリオを作りたいのではなく研修を済ませたい。構築ツールはコンテンツ作成という宿題を押し付ける → 使われず解約。LMS/eラーニング作成ツールが何十年も苦しんだ罠。
2. **生成AIが構築ツールの価値を直撃**: 「プロンプトでロープレを作る」だけなら ChatGPT で今日できる。構築の容易さは差別化にならない。差別化は監修済みコンテンツ・評価ルーブリック・受講証跡。
3. **ハラスメント領域は素人作成コンテンツが危険**: 顧客自作の不適切シナリオで問題が起きると責任・評判リスクがプラットフォームに飛ぶ。監修を外すと「社労士監修の信頼性」という武器を自ら捨てる。
4. **横展開プラットフォームは各縦で専業と戦う**: 汎用を名乗った瞬間、営業ロープレ等の専業と同時に戦う羽目に。

### 最適解: 3段ロケットで「結果的に構築SaaS」になる

**第1段: ハラスメント特化で売る**
措置義務＋証跡という最強の購買理由で最初の顧客と実績を取る。エンジンをマルチテナント・シナリオパック構造で設計しておく。

**第2段: シナリオパックで横展開（作るのは自分、売るのはパック）**
同じ買い手（人事・総務）に隣接パックを売る。本命は**カスハラ対応**（東京都カスハラ防止条例など自治体の条例化が進行 → ハラスメントと同じ「コンプラ支出×証跡ニーズ」構造）。同じエンジン・同じ販路・同じ買い手に2本目 = 最も安い成長。他候補: クレーム対応、医療・介護接遇、1on1、面接練習。

**第3段: ここで初めて「構築SaaS」を開く（顧客は人事ではなく研修会社・社労士）**
シナリオを作る意欲と専門性を持つのは彼ら。「研修ノウハウをAIロールプレイ化して自社商品として売れる」B2B2Bイネーブラーとして構築機能を開放。彼らはコンテンツ制作を宿題と思わない唯一の顧客層であり、販路そのものでもある。レベニューシェアを取るプラットフォーム = 本当の「ロープレ構築SaaS」の完成形。

## 5. 進め方: 作り込む前に「売る」

最大のリスクは収益化手段の選択ミスではなく、**需要検証前の作り込み**。

1. LP＋既存アプリのデモで、**社労士・人事10人にヒアリング**（buyするか、いくらなら買うか）
2. 反応があれば **1社パイロットを有償で**（5〜10万円でよい。無料パイロットは検証にならない）
3. 売れてから SaaS 化の開発投資

## 6. 商用化で必要になる開発（現状とのギャップ）

- 認証 ＋ **組織・受講者管理と受講レポート**（これが本体）
- Stripe 等の請求
- **インフラ分離**: 現在の Supabase は gamify-career 等と相乗り（ref `wrlkcchxdyhlpiywhqua`）。コンプラ商品が他アプリとDB同居は営業・契約上通らない → 商用化時は専用プロジェクトに分離必須
- 会話データの扱いを定めた利用規約・プライバシーポリシー（研修会話は超センシティブ）
- **社労士監修**の名前（信頼性が価格を決める領域）
- Gemini API コストの従量管理（per-seat 価格に原価を織り込む）
- エンジンのマルチテナント／シナリオパック構造（第1段の時点から仕込む）

## 7. リスク

- 営業ロープレ系AIロールプレイ企業が隣接領域に既存。大手eラーニング会社もAI機能を搭載し始めている。勝ち筋は「ハラスメント×グレーゾーン判断」への特化と、社労士チャネルの先取り。
- AIに「ハラスメントをする上司役」を演じさせる品質はモデルのセーフティ調整で揺れる。プロンプトとモデル選定の継続メンテが運用コスト。

## 8. 一行サマリー

広告は論外、B2C月額は脇役、構築SaaSは入口にすると死ぬ。
**「①ハラスメント特化で証跡付き研修として社労士チャネルに売る → ②カスハラ等パックで横展開 → ③研修会社に構築機能を開放」**の順で進め、マルチテナント設計だけは①から仕込む。これが「特化で勝つ」と「構築SaaSという目的地」の両取り。
